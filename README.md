# Лабораторная работа №3

## Выполненные требования

- Навигационное меню реализовано с помощью Flexbox и переносится при недостатке места.
- Раздел «Мои релизы» содержит четыре семантические карточки `article`.
- В карточках указаны название, тип релиза, жанр, обложка и год в элементе `time` с атрибутом `datetime`.
- На мобильном, планшете и компьютере отображается соответственно 1, 2 и 4 карточки релизов в строке.
- Раздел «Студийное оборудование» содержит шесть семантических карточек в CSS Grid.
- На мобильном, планшете и компьютере Grid содержит соответственно 1, 2 и 3 колонки.
- Использованы медиазапросы для контрольных точек 600 px и 900 px.
- Предотвращена горизонтальная прокрутка из-за содержимого карточек и изображений.
- Сохранены требования предыдущей лабораторной по CSS и варианту №9.
- Цвета текста и фона соответствуют требованию контрастности не менее 4.5:1.

## Запуск

Откройте файл `index.html` в браузере.

## Проверка

HTML- и CSS-код провалидированы с помощью сервисов W3C.
